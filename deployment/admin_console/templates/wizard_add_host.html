Step 1: Host Details
The hostname or DNS name of the target machine.
Only needed if the hostname isn't resolvable via DNS.
Which SiLA server package to deploy on this host.
Step 2: Prepare the Target Machine

For Windows targets, enable WinRM:

Run this in an elevated PowerShell on the target machine:

# Enable WinRM with Basic auth
winrm quickconfig -force
winrm set winrm/config/service/auth '@{Basic="true"}'
winrm set winrm/config/service '@{AllowUnencrypted="true"}'

# Ensure the automation user exists
net user automation YOUR_PASSWORD /add
net localgroup Administrators automation /add
Basic auth over HTTP is fine for a local lab network. For production, use HTTPS + certificate auth.

For Linux targets, ensure SSH access:

# Copy your SSH key to the target
ssh-copy-id user@TARGET_HOST

# Ensure Python 3.10+ is installed
python3 --version
